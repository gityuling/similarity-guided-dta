# SGF-DTA：逐靶点收益、门控分层与骨架隔离重复实验

更新：2026-10-26T08:20:44.137622+00:00

本报告考察融合收益在靶点之间的分布，以及门控相对于固定权重融合的额外收益随实验参照条件的变化。

逐靶点和分层分析已完成并复核。骨架隔离新增的两个训练种子正在计算；当前该设置的分析采用原始种子 20261012。

## 逐靶点收益

每个靶点合并五折测试样本，先逐样本平均各训练种子的误差，再计算该靶点的 MSE。

- Davis 化合物 ID 冷启动（3 个训练种子）：SGF 相较基础模型在 331/442 个靶点上降低 MSE；相较固定融合在 191/442 个靶点上降低 MSE。相较固定融合的逐靶点 MSE 差值中位数为 +0.002423。
- KIBA 化合物 ID 冷启动（3 个训练种子）：SGF 相较基础模型在 211/229 个靶点上降低 MSE；相较固定融合在 169/229 个靶点上降低 MSE。相较固定融合的逐靶点 MSE 差值中位数为 -0.002083。
- KIBA 化学身份隔离（1 个训练种子）：SGF 相较基础模型在 210/229 个靶点上降低 MSE；相较固定融合在 158/229 个靶点上降低 MSE。相较固定融合的逐靶点 MSE 差值中位数为 -0.001677。
- KIBA 骨架隔离（1 个训练种子）：SGF 相较基础模型在 212/229 个靶点上降低 MSE；相较固定融合在 133/229 个靶点上降低 MSE。相较固定融合的逐靶点 MSE 差值中位数为 -0.001095。

逐靶点统计同时报告融合相对于基础模型的收益，以及门控在固定融合之上的额外收益。完整结果和“至少 20 个测试化学身份”的敏感性分析见 target_summary.csv。

去除 MSE 改善最大的 10% 靶点后，剩余样本的门控减固定融合 MSE 差值如下。这一分析用于描述收益集中程度。

- Davis 化合物 ID 冷启动：+0.005970；保留 397 个靶点。
- KIBA 化合物 ID 冷启动：-0.001810；保留 206 个靶点。
- KIBA 化学身份隔离：-0.001472；保留 206 个靶点。
- KIBA 骨架隔离：-0.001007；保留 206 个靶点。

## 门控分层

差值定义为 SGF MSE − 固定融合 MSE，负值表示 SGF 更优。参照数量与近邻亲和力分歧按各折验证集三分位数分组；最近邻相似度采用固定区间。下列为近邻亲和力分歧分组的全部结果。

整体差值 -0.002528，95% 区间 [-0.020800, +0.018236]。

- 低分歧组：差值 -0.000194，95% 区间 [-0.005599, +0.005129]；相对 MSE 变化 -0.079%；9,425 对测试样本。

### KIBA 化合物 ID 冷启动

整体差值 -0.002248，95% 区间 [-0.003581, -0.001039]。

### KIBA 化学身份隔离

整体差值 -0.001768，95% 区间 [-0.002930, -0.000629]。

整体差值 -0.001512，95% 区间 [-0.003296, +0.000189]。

各组完整效应、样本量、相对变化及各训练种子结果均保留在 CSV 中，可据此判断较大收益出现在哪些实验参照条件下。

门控本身仅输入结构相似度；参照数量与亲和力分歧用于描述实验参照条件。高分歧组的基础误差也较大，因此绝对收益与相对收益需结合阅读。区间为基于已训练模型的逐组描述性区间。

- 种子 20261012：基础模型 0.44429；近邻预测 0.40359；固定融合 0.36877；SGF 0.36721。数值均为五折平均 MSE。

## 统计与复现

参照池按实验靶点 ID 匹配。参照数量为训练池中的不同化学身份数；近邻分歧为原近邻预测所用 k 个参照标签的相似性加权标准差。各组阈值由验证查询的训练侧协变量确定，保存于 reference_audit.json。Davis 每折内各靶点的参照数相同，故记为 constant。

区间采用 5,000 次配对簇重采样，随机种子 20261026。药物 ID 冷启动和身份隔离以化学身份为簇；骨架隔离另按骨架为簇重采样，图中采用骨架簇区间。少于 10 个簇的组仅显示点估计，图中为空心点。所有预定分组均保留。

verification.json 记录独立复核：重新计算每种协议的 120 个验证/测试查询的近邻信息、全部逐靶点与分层点估计，以及整体和高分歧组的重采样区间。
